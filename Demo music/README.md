# 데모 기본 음악

이 폴더에 음악 파일을 넣고 배포하면, 해당 데모 공연을 열었을 때 이 음악이 바로 재생돼요 (스페이스로 재생).

- `demo.mp3` → 데모 1 (힙합 드릴, 1분 40초까지 사용)
- `demo2.mp3` → 데모 2 (걸스 스타일, 2분 52초)
- 파일이 없으면 지금처럼 무음으로 조명만 재생돼요
- 사용자가 데모 공연에 직접 노래를 올리면 그쪽이 우선이에요

⚠️ GitHub Pages에 공개로 올라가 누구나 받을 수 있으니, 직접 만들었거나 재배포가 허용된(무료/CC0 등) 음원만 넣어 주세요.
