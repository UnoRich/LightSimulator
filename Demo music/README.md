# 데모 기본 노래

각 폴더에 `music.mp3`(또는 `music.m4a`)라는 이름으로 넣고 배포하면, 그 데모를 열었을 때 기본 노래로 바로 재생돼요 (Space로 재생).

- `Demo1/music.mp3` → 데모 1 (힙합 드릴, 2분 31초)
- `Demo2/music.mp3` → 데모 2 (걸스 스타일, 2분 52초)
- 파일이 없으면 노래 없이 조명만 재생돼요
- 사용자가 그 데모에 직접 노래를 올려 둔 상태에서 데모 버튼을 누르면, 지우고 기본 노래로 바꿀지 물어봐요

⚠️ GitHub Pages에 공개로 올라가 누구나 받을 수 있으니, 직접 만들었거나 재배포가 허용된(무료/CC0 등) 음원만 넣어 주세요.
